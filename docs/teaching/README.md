# First Ten teaching kit

EDU-001 · version 1.0 · 2026-10-18 · source baseline `d6931694d43d04b0bfdb78dafe1c3ba035366c3d`.

The kit is runnable with paper or an accessible document, without an account, AI or paid resources. The 60-minute timing matches the pitch: 10 minutes framing/own thinking, 20 evidence, 20 marketing-test design and 10 peer check/reflection. A one-week field assignment follows; the private/simulated alternative has the same rubric opportunities. No lesson delivery or effectiveness study is claimed.

The public Markdown files are the editable source. Run `python3 docs/teaching/build-kit.py` after edits to regenerate HTML; page markers preserve handout boundaries. After changing text, print the regenerated HTML to A4 PDF with headers/footers off, replace `public/teaching/first-ten-teaching-kit.pdf`, and inspect every rendered page. The Python script regenerates HTML only; it does not silently refresh the PDF. The manifest does not claim that a web deployment or `/teach` route exists. Refer to the [pedagogy map](pedagogy-map.md), [Marketing Lab contract](../marketing/marketing-lab-contract.md), [research protocol](../../research/value-test-plan.md) and [kit verification](verification.md) for boundaries.

This curriculum is independent of participant research: student work is not automatically submitted to First Ten or uploaded to AI. Instructor delivery decisions, dates, private submission route and institution-specific participant arrangements are filled locally before assignment. Keep the student’s original structure visible; no grade depends on customers, network, spending, AI usage or fabricated positive outcomes.
